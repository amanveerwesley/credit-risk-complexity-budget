# Module 4 Assignment 2: Complexity Budgeting

Notebook: `a2_complexity_budget.ipynb`

## How to run
1. Open this folder in VS Code.
2. Select the relevant Python environment (or run `pip install -r requirements.txt`).
3. Close other heavy programs so the timings are steady.
4. Run All. It takes well under a minute.

## Inputs (already in this folder)
- `uci_credit_default.zip`: the UCI raw archive used in Assignment 1.
- `a1_split_ids.csv`: the Assignment 1 train, validation and test assignment.

## Outputs (written to `a2_outputs/`)
- `results.json`: every number used in the report.
- `runtime_table.csv`, `cv_table.csv`, `scaling_table.csv`
- `fig1_convergence.png`, `fig2_runtime.png`, `fig3_performance.png`

The Assignment 1 test partition is not used anywhere in this notebook.
